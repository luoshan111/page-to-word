# 网页导出到 Word：使用指南

适用插件版本：1.1.0。文档更新日期：2026-10-01。

[返回项目首页](../README.md)

## 1. 准备好浏览器和插件文件

使用电脑上的 Edge 或 Chrome，并准备一个能够打开 `.docx` 的文档应用，例如 Microsoft Word。插件生成文件时不要求本机安装 Word；阅读和编辑文件时才需要相应应用。

打开 [GitHub 仓库](https://github.com/luoshan111/page-to-word)，点击 **Code → Download ZIP**，或者直接[下载源码 ZIP](https://github.com/luoshan111/page-to-word/archive/refs/heads/main.zip)。

将 ZIP **完整解压**到一个长期保留的位置，例如 `D:\BrowserExtensions\page-to-word-main`。这是示例位置，可自行更改。确认文件夹结构类似：

```text
page-to-word-main/
├── manifest.json
├── popup.html
├── popup.js
├── src/
├── vendor/
└── ...
```

安装时要选择上面这一层文件夹。若解压后外面又套了一层同名目录，请继续进入，直到直接看到 `manifest.json`。

**不需要运行 npm、不需要 API Key，也不需要启动网页服务器。** 不要双击 `popup.html` 使用：它依赖浏览器扩展环境。

## 2. 安装到 Edge

1. 打开 Edge，在顶部地址栏输入 `edge://extensions` 并回车。
2. 打开页面上的“开发者模式”。
3. 点击“加载解压缩的扩展”或相近名称的按钮。
4. 选择第一步中直接包含 `manifest.json` 的文件夹，点击“选择文件夹”。
5. 页面出现“网页导出到 Word”卡片，且处于启用状态，即完成加载。

这些步骤对应 [Edge 官方本地安装说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。按钮文字和位置可能随浏览器语言或版本变化。

## 3. 安装到 Chrome

1. 打开 Chrome，在顶部地址栏输入 `chrome://extensions` 并回车。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择直接包含 `manifest.json` 的文件夹。
5. 确认“网页导出到 Word”卡片出现并已启用。

步骤可参考 [Chrome 官方本地加载说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。本项目已做 Edge 自动检查，Chrome 人工安装与交互尚未实测。

## 4. 找到扩展按钮

点击浏览器工具栏上的扩展菜单，找到“网页导出到 Word”，点击即可打开弹窗。也可以使用菜单中的“固定”或“在工具栏中显示”选项，将入口留在工具栏上。

安装文件夹需要保留在原位置。移动或删除它会影响后续加载；确需搬动时，应从新位置重新加载扩展。

## 5. 第一次导出文章

1. **打开文章本身。** 先用一篇普通博客或资讯文章尝试，不要停留在扩展管理页。
2. **等待正文加载。** 如有“阅读全文”或折叠章节，先展开；如需滚动才显示后文，先滚动加载。
3. **打开扩展。** 点击“网页导出到 Word”。弹窗标题为“导出当前网页”。
4. **点击“导出为 .docx”。** 生成过程中保持弹窗打开，不切换标签页。
5. **选择保存位置。** 出现文件保存对话框后选择文件夹并保存。你可以在这里修改文件名。
6. **确认下载完成。** 到浏览器下载列表查看文件状态。在 Windows 上也可以按 `Ctrl+J` 打开下载列表。
7. **打开文档检查。** 用 Word 查看标题、来源链接、正文和表格是否符合需要，再继续编辑。

正常情况下，文件名来自正文标题；没有识别到标题时使用网页标签标题，再无标题时使用“网页内容”。不允许出现在文件名中的字符会被替换。

### 弹窗提示代表什么

| 提示 | 含义与下一步 |
| --- | --- |
| 正在读取网页… | 提取当前页面文字，请保持弹窗打开 |
| 正在生成 Word 文档… | 将提取结果转换为 DOCX，请等待 |
| 请选择文档保存位置… | 浏览器正在发起保存，请查看文件对话框 |
| 文档已提交浏览器下载… | 已创建下载任务；请在下载列表确认最终保存结果 |
| 图片、音视频和嵌入内容未导出 | 正文仍可导出，但这些内容没有包含在文件里 |
| 表格中的合并单元格已展开为普通单元格 | 原表格结构已简化，请在 Word 中检查并整理 |

“已提交下载”不等于文件已成功写入磁盘。取消保存、关闭弹窗或下载中断时，请先检查下载列表，再决定是否重试。

## 6. 用随附示例确认安装

如果暂时没有合适的文章，可以使用插件文件夹里的 [tests/fixture.html](../tests/fixture.html)：

1. 到扩展管理页，打开“网页导出到 Word”的“详情”。
2. 启用“允许访问文件网址”或类似选项。这个设置用于读取本机 `file://` 页面，导出普通网站通常不需要。
3. 用已安装扩展的同一个浏览器打开 `tests/fixture.html`。可以按 `Ctrl+O` 选择该文件。
4. 按第五节操作导出。

预期内容包括：

- 标题“扩展导出测试”。
- “这是一篇中文文章，用于检查实际下载。”，其中“中文文章”加粗。
- “第一步”“第二步”两项列表。
- 一张两列的表格，包含“名称 / 数量”和“文档 / 1”。
- 来源链接；本例是本地文件路径，因此会包含本机路径信息。

示例中的“导航”应被过滤。只想测试普通网页时，可以直接使用第五节，不必打开本地文件权限。

## 7. 哪些内容可以导出

通常适合正文清晰的文章、博客、资讯页，以及结构简单的文档页面。文字、标题、基础格式、代码块、列表、引用、链接和基础表格可保留。

导出范围是当前页面已经加载并处于可见状态的正文结构，可以包含屏幕下方的内容；它不局限于当前屏幕截图，也不会自动翻到下一页。它目前没有“仅导出选中文字”功能。

需要留意的情况：

| 场景 | 当前表现 |
| --- | --- |
| 登录后才能查看的文章 | 登录并加载到当前页面的普通正文可以尝试导出；特殊编辑器或嵌入内容可能失败 |
| 图片、扫描件、图表 | 不导出图片，也不做 OCR |
| 视频、音频、嵌入网页 | 不读取媒体或嵌入区域内部内容 |
| 多页文章、无限滚动 | 不自动翻页；只处理本次已加载且仍保留在页面中的内容 |
| 复杂列表或表格 | 标记使用文本，合并单元格关系会简化，可能需要手动调整 |
| 网页配色、字体、多栏布局 | 使用统一的 Word 样式，不保证与网页外观相同 |
| 浏览器设置页、扩展商店、PDF 阅读器 | 请换成普通 HTML 文章页面 |

导出文档会包含原网页链接。提取和生成在本机执行；插件本身不上传正文。

## 8. 更新与卸载

### 从 ZIP 安装的用户

1. 重新下载最新源码 ZIP 并完整解压。
2. 若没有修改过插件代码，可以将新文件更新到原安装目录。若曾自行修改，先备份自己的修改。
3. 打开扩展管理页，找到插件，点击“重新加载”或刷新图标。
4. 重新打开目标文章和插件弹窗，再次导出。

如果使用了新的目录，则在扩展管理页移除旧插件，再从新目录加载，避免混淆两个版本。移除扩展不会删除之前保存的 Word 文件。

### 使用 Git 的开发者

在本地仓库中执行：

```sh
git status
git pull --ff-only
```

若存在未提交的代码修改，先保存或提交。若拉取提示分支分叉，先处理本地改动，不要直接覆盖。拉取成功后，在扩展管理页重新加载。

### 停用或卸载

到扩展管理页关闭插件开关即可停用；点击“移除”可卸载。确认不再需要后，再自行删除本地插件目录。已导出的 Word 文件保留在你原先选择的位置。

## 9. 常见问题

| 问题或提示 | 处理方法 |
| --- | --- |
| 找不到“加载已解压…”按钮 | 检查是否开启开发者模式；受单位管理的浏览器可能限制本地扩展安装 |
| 无法加载 / 找不到 manifest | 先完整解压，再选择直接包含 `manifest.json` 的目录，而不是 ZIP、上一级目录或 `src` 目录 |
| 点击 `popup.html` 没反应 | 按第二或第三节安装扩展，再从浏览器工具栏打开 |
| 浏览器内部页面和扩展商店不允许读取 | 切换到普通文章页面后重试 |
| 没有找到当前网页 | 回到文章标签页，关闭并重新打开扩展 |
| 没有找到可导出的文字 | 等待加载、展开正文后重试；若主要内容是图片或嵌入页面，当前版本无法读取 |
| 无法读取此页面 / 正文提取失败 | 等待页面加载或刷新；仍失败时用随附示例区分是安装问题还是站点兼容问题 |
| 请开启“允许访问文件网址” | 在插件详情中启用该选项，再重试本地 HTML |
| 页面内容过大 | 使用网站提供的较短文章或独立章节页；选中文字不会缩小本版本的导出范围 |
| 下载未开始 / 取消保存 | 检查是否取消了对话框或被浏览器阻止，重新选择可写目录后导出 |
| 已提交下载，但找不到文件 | 打开下载列表，查看实际路径和是否完成，不要仅凭弹窗文字判断 |
| 文档缺少后半部分 | 先加载、展开内容后再导出；分页文章需要分别打开，虚拟滚动页面仍可能无法完整提取 |
| 导出了额外菜单或缺少正文 | 当前使用通用正文识别规则，特殊站点需要适配；提交可复现的问题信息 |
| 文档图片缺失或版式不同 | 属于当前功能范围，详见第七节 |
| 生成文档时发生错误 | 重新打开扩展重试；若仍失败，更新插件并用示例页面检查 |

## 10. 反馈问题

在 [GitHub Issues](https://github.com/luoshan111/page-to-word/issues) 中提供：

- 浏览器名称、版本和插件版本。
- 能公开访问的示例网页链接，或可复现问题的精简 HTML。
- 操作步骤、完整错误提示、期望结果与实际结果。
- 是所有网页失败，还是仅某个网站失败；随附示例能否导出。

该仓库及问题区是公开的。请使用可公开的示例，避免附上登录凭据或包含私密内容的完整导出文件。

自动检查的历史记录与未验证事项见 [CHECKS.md](../CHECKS.md)。
